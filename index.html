📲 How Chinexo Sync Works
All data lives on your device. To share with teachers or backup to another phone, use the steps below. No internet required.
⚠️ Always export a backup before importing. Importing will replace existing data for this school.
For Admin — Share Data with Teachers
1
Export Your Data
Tap the button below. A JSON file will download to your phone.
2
Share via WhatsApp
Open WhatsApp → find the teacher → tap Attach → Document → select the JSON file you just downloaded.
3
Teacher Imports on Their Device
Teacher opens Chinexo → goes to Sync tab → taps "Import Data" → selects the file received from WhatsApp.
For Teachers — Receive & Import Data
4
Import Received File
Tap below, select the JSON file from admin. Your local data will be updated.
